# Kerry Ann Burke — Jekyll portfolio starter

A work-first cinematic portfolio for GitHub Pages.

## Deploy

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Copy these files to the repository root and push to the default branch.
3. In **Settings → Pages**, select **Deploy from a branch**, your default branch, and `/ (root)`.
4. Wait for the Pages build and visit `https://YOUR-USERNAME.github.io/`.

This uses GitHub Pages' native Jekyll build. No JavaScript toolchain required.

## Edit

- Add or edit Markdown files in `_projects/`.
- Use `artwork: /assets/images/filename.jpg` in project front matter for real project artwork.
- Add external links with:

  links:
    - label: Read screenplay
      url: https://example.com/screenplay

- Replace placeholders on About and Contact with approved copy.
- The `_posts/` folder can be added later when you're ready to blog.

## Local preview

Install Ruby/Bundler and `github-pages` gem, then run `bundle exec jekyll serve` after creating an appropriate Gemfile. Or use a local Jekyll installation with `jekyll serve`.

## Content caveat

This is a designed starter, not a verified full migration of the live Carrd site. Review the draft loglines and transfer the original copy, imagery, reviews and links before publication.
